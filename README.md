mend — one patch tool for every AI edit format. It reads a unified diff (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, or JSON text-editor tool calls, and applies them to a tree of text files — all or nothing, with tiered fuzzy line matching, exact exit codes and stdout. Node 22+, standard library only.

## Run it

```sh
node main.ts [options] [PATCH]
```
